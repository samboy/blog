Why I stick with Lua 5.1

Sometimes, people argue that Lua 5.1 should no longer be supported, and everyone should move on to Lua 5.5. This is not feasible.

As a poster on Lobsters points out, PUC Lua breaks compatibility between point releases, and applications that embed Lua need to not break scripts used by the applications.

There’s a reason I forked Lua 5.1 and named it Lunacy—that guarantees that any future changes to Lua don’t break the scripts I use to make this blog nor the scripts that make MaraDNS’ documentation.
